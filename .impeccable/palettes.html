Palette options

Each option is the same home-page excerpt rendered from tokens only, light and dark side by side. Type, layout and spacing are unchanged so you are judging colour alone. Option 0 is the current palette for reference.

0 · Current: Clay

Warm grey paper, near-black ink, burnt orange. Reference point.

1 · Drafting Blue

Cool, slightly blue paper and navy-black ink with a cobalt accent. Reads like an engineering drawing: precise, calm, trustworthy. The safest fit for a recruiter audience, and the closest to "spec sheet". Risk: blue is the most common tech accent, so the type and heavy rules have to carry the identity.

  • bg #eceef0 / #0d1218
  • ink #0e1621 / #e6eaf0
  • accent #1d4ed8 / #86a8ff

2 · Signal Green

Neutral bone paper with a deep, inky green. Green already means "Live" on this site, so the accent and the status dot merge into one colour that says "running in production", which is the first positioning claim. Quiet and confident. Risk: the separate green Live dot goes away (it becomes the accent), and dark mode needs care to avoid a terminal look.

  • bg #efefe8 / #101412
  • ink #121613 / #e7ebe6
  • accent #0b6b47 / #5fd39a

3 · Oxblood

Warm paper with a dark wine-red accent. More editorial and grown-up than the current orange, and the highest contrast accent on light (7.9:1). Feels like a printed annual report. Risk: closest to the current warm world, so it's an evolution, not a change.

  • bg #f3efe9 / #161213
  • ink #1b1517 / #efe8e6
  • accent #8c1c2e / #ff8a96

4 · Hi-Vis

The bold one. Black and off-white with a safety-yellow used as a fill, never as text: a highlighter block behind the 77%, the primary button, link underlines. Links themselves stay ink. Most memorable of the set and very "spec sheet / site signage". Risk: yellow can't be used for text on light, so the accent splits into two roles (fill vs text), which is a small CSS change.

  • bg #f0efea / #121212
  • ink #111111 / #ededea
  • fill #ffd23f
